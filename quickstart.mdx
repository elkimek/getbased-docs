Run getbased on a computer or server you control, then open its private HTTPS address in your browser. No getbased account is required. A fresh profile starts with a short guided tour, then opens guided chat so you can decide what to add first.

To explore before installing, try the [public sample demo](https://getbased-demo.vercel.app). It uses fictional records and cannot import or save personal data. Existing hosted users should follow [Move to self-hosting](/guides/move-to-self-hosting).

<Note>
Charts, manual meal and lab entry, correlations, comparisons, JSON import, and data export work without an AI provider. PDF/image import, meal-photo or nutrition-label analysis, chat, Current Focus generation, and AI interpretation need a provider.
</Note>

## Steps

Already have Codex, OpenCode, Hermes, Grok Build, or OpenClaw installed? You can use it as your AI provider through [CLI agents and Companion](/guides/cli-agents). This is optional; non-AI features need only the browser app.

<Steps>
  <Step title="Install and open the app">
    Follow [Self-hosting](/guides/self-hosting) to install the prebuilt release package with Node.js 24.20 or later within version 24. In the folder containing your downloaded `getbased-self-host.tgz`, run:

    ```bash
    npm install --global ./getbased-self-host.tgz
    getbased
    ```

    Keep that terminal open. Install Tailscale on the host and each device, then run `tailscale serve --bg http://127.0.0.1:8000` in another terminal on the host. Open the full private HTTPS address it prints, including on the host itself. Bookmark this address before adding records.

    **Install as a PWA (optional)**

    You can install getbased as a Progressive Web App for a native-like experience on desktop or mobile where your browser supports installation. After the app finishes caching, browser-local features can work offline. Installation options vary by browser and operating system; network providers and optional model downloads have separate connectivity needs. See [App updates and offline use](/guides/app-updates) for update prompts and recovery.

    | Browser | How to install |
    |---|---|
    | Chrome / Edge | Click the install icon in the address bar, or open the browser menu and select "Install getbased" |
    | Safari (iOS) | Tap Share, then "Add to Home Screen" |
    | Firefox | Open the browser menu and select "Install" |

    Choose whether to use an installed PWA before restoring records; some browsers keep its storage separate. The [installation guide](/guides/self-hosting) also covers building from source, updates, startup, and optional services.
  </Step>

  <Step title="Take the first-visit tour">
    The first time you open a fresh profile, getbased starts a five-step empty-profile tour. It points out the guided chat, demo profiles, profile switcher, and Settings.

    When the tour finishes, guided chat opens. Chat is the main first-run path: it asks for context only when useful, then routes you to labs, DNA, wearables, light setup, or first-test planning.

    You can replay the populated app tour later from **Settings → Display → Guided Tour**.
  </Step>

  <Step title="Connect AI only when you need it">
    An AI provider is required for PDF/image import, meal-photo or nutrition-label analysis, AI chat, Current Focus generation, and AI-powered interpretations. You can explore demo data or enter values manually before setting one up.

    Open **Settings** (gear icon) and select **AI**. getbased supports several provider paths:

    - **OpenRouter** — easiest to start. Use one-click OAuth or paste an API key.
    - **PPQ** — pay-per-query with crypto top-ups, no KYC, and optional Private TEE mode.
    - **Routstr** — decentralized Bitcoin AI with a built-in Cashu wallet.
    - **Venice AI** — hosted AI with optional browser-side message encryption and limited attestation checks.
    - **Local AI** — a direct connection to Ollama, LM Studio, Unsloth Studio, Jan, or another compatible server on this device, your LAN, or a remote host.
    - **Custom API** — any OpenAI-compatible endpoint.

    See [Connect an AI provider](/ai-providers) for a full comparison and setup instructions. After connecting, use **Settings → Data → Test models on lab reports** to [compare accuracy and speed](/guides/ai-model-testing) before importing your own data.

    **Voice is optional and configured separately.** Open **Settings → Voice** to download on-device speech models, connect a compatible voice server, or add xAI or ElevenLabs for dictation and spoken replies. See [Use voice in AI chat](/guides/voice).
  </Step>

  <Step title="Add data or load a demo">
    **Start with guided chat**

    On a new profile, click **Start guided chat**. Chat can help you decide whether to import labs, add DNA, connect wearables, set up light context, or fill Manage → Context later.

    With a compatible chat model, you can also describe a changed routine or paste an existing health summary. getbased can prepare updates for several records; review each **Apply / Discard** card before saving. You can fill context manually at any time. See [Health updates in chat](/guides/health-updates-in-chat).

    **Import directly**

    Use the header import button or drag files onto the page. getbased recognizes lab PDFs, lab photos/screenshots, raw DNA files, getbased JSON exports, and database bundles. When an AI provider is connected, the empty state also shows **Import directly**.

    **Try a demo profile**

    If you do not have data on hand, load one of the built-in demo profiles:

    - **Sarah** — iron, hormones, Oura, cycle context, supplements, lifestyle context, and a multi-week meal history
    - **Alex** — metabolic health, Withings body composition, OAT and EMF assessment data, and a multi-week meal history

    You can also load demo profiles from the profile switcher in the header.

    Demo context-card insights are precomputed, so simply browsing either profile does not use AI inference. If you change a demo card, a local model can update it automatically. Cloud and other potentially paid models require an explicit **Enable live AI** confirmation before recalculating demo insights.

    **Enter values manually**

    For lab values, open a marker detail view and click **+ Add Value Manually**, fill an empty cell in **Compare dates**, or create a marker from **Custom markers**. For meals, use **Daily Nutrition → Log meal** and type the reviewed values without a photo. For body metrics, use **Biometrics** or the **Biometrics Overview** widget to log weight, blood pressure, resting heart rate, or [waist and abdominal measurements](/guides/body-measurements).
  </Step>

  <Step title="Explore the dashboard">
    The dashboard is a customizable overview, not the only place where work happens. The default widgets surface Biological Coherence when available, current focus, biological age, recommended next steps, priority markers, quick markers, daily nutrition, biometrics, light context, and key trends.

    Use the sidebar on desktop, or swipe the bottom tabs and use the menu on mobile, to move through:

    - **Labs** — biomarker charts, tables, heatmaps, and marker detail views
    - **Biology Scores** — Biological Coherence, score domains, and coverage planning
    - **Biometrics** — wearables, manual body metrics, connected sources, and cycle tracking
    - **Nutrition** — meals, targets, history, and Fuel Mix Context
    - **Supplements & Meds** — supplement and medication history
    - **Light** — sun sessions, therapy devices, indoor light, and measurement tools
    - **Genome** — raw DNA, APOE, mtDNA, and SNP context
    - **Insight** — Current Focus, AI insights, Manage → Context, and synthesis
    - **Recommendations** — data-linked next steps across all lenses
    - **Compare dates** and **Correlations** — analysis tools for lab changes and marker pairs

    See [Use the dashboard](/guides/dashboard) for the widget and layout controls.
  </Step>
</Steps>
